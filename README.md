# T3 Antigravity Context Bar

Real-time, zero-dependency macOS menu bar monitor and CLI for **T3 Code** running with the **Google Antigravity** provider (Gemini models).

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Platform: macOS](https://img.shields.io/badge/Platform-macOS-blue.svg)]()
[![Python: 3.10+](https://img.shields.io/badge/Python-3.10+-brightgreen.svg)]()

## Why This Exists

When using Google Antigravity inside T3 Code, per-turn token usage snapshots are not piped through the standard ACP streaming interface to T3 Code's Electron UI, causing the built-in context meter badge to remain suppressed.

However, exact token telemetry is recorded locally in real time:
- **T3 Code State DB:** `~/.t3/userdata/state.sqlite` (`projection_threads`, `provider_session_runtime`)
- **Antigravity DB:** `~/.t3/userdata/providers/antigravity/*/antigravity-acp/conversations/<session-id>.db` (`gen_metadata` table)

**T3 Antigravity Context Bar** reverse-engineers the protobuf telemetry records from SQLite without external dependencies or protobuf compilers, displaying live token usage, cache hit ratios, and handoff warnings directly in your macOS Menu Bar.

## Visual Design & Status Thresholds

| Status | Threshold | Color | Menu Bar Indicator | Recommendation |
| :--- | :--- | :--- | :--- | :--- |
| **Healthy** | `< 100,000` tokens | Green (`#3fb950`) | `● T3: 56.1k (47%)` | Safe to continue deep work |
| **Warning** | `100,000 – 119,999` tokens | Amber (`#d29922`) | `● T3: 102.6k (85%)` | Plan `/handoff` soon |
| **Critical** | `≥ 120,000` tokens | Red (`#f85149`) | `● T3: 121.0k (101%)` | Ceiling reached; trigger handoff immediately |

## Quick Start & Installation

Clone the repository:
```bash
git clone https://github.com/o-kd-singh-o/t3-antigravity-context-bar.git
cd t3-antigravity-context-bar
```

### Option 1: Native macOS Status Bar App (Recommended)
Zero third-party dependencies. Built natively in Swift using AppKit (`LSUIElement = true`).

```bash
# Build the native app
make build

# Launch the app
make run
# or
open T3AntigravityContextBar.app
```

To have it start automatically on login:
1. Open **System Settings** > **General** > **Login Items**.
2. Click **+** and add `T3AntigravityContextBar.app`.

---

### Option 2: SwiftBar / xbar Plugin
If you already use [SwiftBar](https://swiftbar.app/) (`brew install swiftbar`) or [xbar](https://xbarapp.com/):

```bash
# Symlink plugin to SwiftBar's default plugin directory
make install-swiftbar
```

---

### Option 3: Terminal CLI & Watch Mode
You can also run or monitor directly from your terminal:

```bash
# Single snapshot
python3 -m t3_monitor

# Continuous terminal monitor (updates every 5 seconds)
python3 -m t3_monitor --watch 5

# Output as JSON
python3 -m t3_monitor --format json

# Output in SwiftBar format
python3 -m t3_monitor --format swiftbar
```

## Dropdown Menu Features

Clicking the menu bar item reveals:
- **Active Thread Details:**
  - Full title of the active/focused thread
  - Monospaced ASCII progress bar: `[████████░░░░░░] 69.5k / 120.0k (58%)`
  - Health badge: `🟢 Context healthy — continue work normally`
- **Context Breakdown Submenu:**
  - **Total Active Context:** Total prompt tokens currently in context
  - **Cached Context:** Number and % of cached prompt tokens (e.g. `66,414 tokens (95.6%)`)
  - **New Turn Input:** Uncached tokens from latest prompt turn
  - **Latest Output:** Completion tokens generated by Gemini
  - **Reasoning / Thought:** Internal reasoning/thought tokens (Gemini 2.0/Flash)
  - **Remaining Headroom:** Remaining tokens before hitting the 120k ceiling
- **Recent Threads Submenu:**
  - Lists other running and recent threads with their respective token usage and statuses
- **Quick Actions:**
  - `🔄 Refresh Now` (`Cmd+R`)
  - `Open T3 Code` (`Cmd+O`)
  - `Quit T3 Antigravity Context Bar` (`Cmd+Q`)

## Configuration

You can customize thresholds and paths via environment variables or CLI flags:

| Variable | Default | Description |
| :--- | :--- | :--- |
| `T3_WARN_THRESHOLD` | `100000` | Warning threshold in tokens (amber dot) |
| `T3_MAX_THRESHOLD` | `120000` | Hard ceiling threshold in tokens (red dot) |
| `T3_POLL_INTERVAL` | `10` | Default refresh interval in seconds |
| `T3_STATE_DB` | `~/.t3/userdata/state.sqlite` | Path to T3 Code SQLite database |
| `T3_CONV_DIR_PATTERN` | `~/.t3/userdata/providers/antigravity/*/antigravity-acp/conversations` | Path/glob to Antigravity conversation DBs |

Example:
```bash
T3_WARN_THRESHOLD=80000 T3_MAX_THRESHOLD=100000 python3 -m t3_monitor
```

## Architecture & Codebase Design

The implementation is structured around **deep modules** with clear **seams**:

```
t3_monitor/
├── proto.py         # Seam 1: Pure-Python Protobuf decoder (decodes varints, tags, and UsageMetadata)
├── config.py        # Centralized configuration and env variable loader
├── db.py            # Seam 2: Read-only SQLite reader (opens DBs with file:...mode=ro)
├── engine.py        # Seam 3: Aggregator, thread ranking, metric calculations, and health classification
└── formatters/      # Seam 4: Output generators
    ├── swiftbar.py  # BitBar / SwiftBar format output
    ├── json_fmt.py  # Structured JSON generator (used by Swift app and APIs)
    └── terminal.py  # ANSI color-coded terminal dashboard

macos_app/
└── Sources/T3ContextBar/
    ├── Models.swift              # Decodable DTOs
    ├── MonitorService.swift      # Background worker invoking python monitor engine
    ├── StatusBarController.swift   # NSStatusBar and NSMenu manager
    └── main.swift                # AppKit entry point (LSUIElement)
```

## Testing (TDD)

Unit tests cover every seam without external network or database dependencies:
- **`tests/test_proto.py`**: Protobuf wire encoding, varint decoding, nested `UsageMetadata` field extraction.
- **`tests/test_db.py`**: SQLite reader with synthetic mock databases and multi-thread correlation.
- **`tests/test_engine.py`**: Threshold logic (healthy/warning/critical), percentage calculation, and headroom calculation.
- **`tests/test_formatters.py`**: SwiftBar and JSON serialization.

To run the test suite:
```bash
make test
# or
python3 -m unittest discover tests
```
